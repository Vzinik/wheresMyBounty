# chrome-extention

### extention to control twitch

This repo willl contain a test or tutorial extention and then an extention to overwatch twitch live streams will be made.
 
> ###### Features
> 
> - togglable on/off switch for the extention     
> - shows the number of coins collected     
> - should be capable of refressing the twitch page if any error occurs   
> - automatic popup notification if twitch page is not opened   
> - snoose and close button for the above notification    
> - automatic notification if all the coins for the week have been collected and automatic switching off the extention    
> - changing the channel of twitch if the current channel goes offline
